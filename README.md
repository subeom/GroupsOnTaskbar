# Taskbar Groups

Taskbar Groups is a packaged WinUI 3 launcher for Windows 11. It gives you one taskbar pin that opens grouped desktop application shortcuts without injecting into Explorer.

## Prerequisites

- Windows 11
- .NET 10 SDK
- Windows Developer Mode enabled (Settings → System → For developers). Enabling it requires administrator rights.
- Administrator rights once, to trust the local development signing certificate before installing the MSIX

Install the WinUI project templates if they are not already available:

```powershell
dotnet new install Microsoft.WindowsAppSDK.WinUI.CSharp.Templates
```

## Restore, build, test, and run

From the repository root:

```powershell
dotnet restore .\GroupsOnTaskbar.sln
dotnet build .\GroupsOnTaskbar.sln -c Debug
dotnet test .\tests\GroupsOnTaskbar.Tests\GroupsOnTaskbar.Tests.csproj -c Debug
dotnet run --project .\src\GroupsOnTaskbar.App\GroupsOnTaskbar.App.csproj -c Debug -p:Platform=x64
```

`dotnet run` launches the packaged WinUI app with package identity support supplied by the Windows App SDK build tooling. Developer Mode must be enabled for local registration.

## Create a development package

Build a signed x64 MSIX package for the current user:

```powershell
.\scripts\New-DevelopmentPackage.ps1
```

The script:

- reuses or creates a code-signing certificate in `CurrentUser\My` with subject `CN=Taskbar Groups Development`
- exports only the public certificate to `.\artifacts\package\TaskbarGroupsDevelopment.cer`
- imports that public certificate into `CurrentUser\TrustedPeople` and `CurrentUser\Root`
- imports it into `LocalMachine\TrustedPeople` when run elevated, and otherwise prints the elevated command you still need to run
- publishes the WinUI app as a signed x64 MSIX
- copies the newest package to `.\artifacts\package\TaskbarGroups_0.1.0.0_x64.msix`

Windows validates MSIX signatures against machine-scoped trust. If the script reported
that the certificate is not trusted for the local machine, run this once from an
elevated PowerShell prompt:

```powershell
Import-Certificate -FilePath .\artifacts\package\TaskbarGroupsDevelopment.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople
```

Skipping this step makes installation fail with `0x800B0109`
("The root certificate of the signature in the app package or bundle must be trusted").

Install the generated package for the current user:

```powershell
Add-AppxPackage .\artifacts\package\TaskbarGroups_0.1.0.0_x64.msix
```

## Pin Taskbar Groups from Start

After the package is installed:

1. Open Start.
2. Search for **Taskbar Groups**.
3. Right-click the app.
4. Choose **Pin to taskbar**.

The pinned taskbar icon is the single MVP entry point for launching your configured groups.

## Configuration and logs

When installed as a packaged app, Taskbar Groups stores local data under:

- Configuration: `%LOCALAPPDATA%\Packages\GroupsOnTaskbar.TaskbarGroups_*\LocalState\settings-v1.json`
- Logs: `%LOCALAPPDATA%\Packages\GroupsOnTaskbar.TaskbarGroups_*\LocalState\Logs\taskbar-groups.log`
- Previous log after rotation: `%LOCALAPPDATA%\Packages\GroupsOnTaskbar.TaskbarGroups_*\LocalState\Logs\taskbar-groups.previous.log`

The `*` portion is the package family suffix generated by Windows from the publisher identity.

## MVP limitations

The current MVP intentionally does **not** provide:

- Explorer injection or custom controls inside the Windows taskbar
- more than one taskbar pin
- shortcut types beyond `.exe` and `.lnk`
- Microsoft Store app discovery or activation by AppUserModelID
- start-at-login behavior
- system tray or notification-area integration
